# CodeAlpha Image Gallery (Frames)
**Task 1** of the CodeAlpha Frontend Development Internship: a modern, responsive photo gallery built with HTML, CSS and JavaScript.
## Live demo
**https://pakeezaa58-tech.github.io/CodeAlpha_ImageGallery/**
## Features
- 24 real photographs in two categories: **Nature** and **Architecture**
- Full-screen hero section with a parallax effect
- Masonry grid that changes from 3 to 2 to 1 columns on smaller screens
- Category filters (All, Nature, Architecture) with a live photo count
- Hover effects: smooth zoom, gradient overlay, title and photographer credit
- Loading shimmer and fade-in animations as photos scroll into view
- Lightbox viewer with next and previous buttons, a thumbnail strip, a blurred background and a photo counter
- Keyboard controls (arrow keys and Esc) and swipe support on phones
- A backup picture appears if a photo cannot load

## Technologies

HTML5, CSS3 (columns, transitions, backdrop-filter, media queries), JavaScript (ES6)

## How to run

1. Download or clone this repository.
2. Open `index.html` in a browser.
3. An internet connection is needed because the photos load from Unsplash.
